## Provenance rule

Authored identity notes, historical dialogue, synthetic training examples, generated cartridges, test reports, and actual autobiographical interactions are different evidence classes. Preserve the source and do not silently convert one class into another.

When legacy material conflicts with current authored identity, preserve the conflict rather than rewriting the archived source.
